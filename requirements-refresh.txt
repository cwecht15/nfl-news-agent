# Slim dependency set for the workflows that only collect roster-facing data:
# refresh.yml, injuries.yml and inactives.yml.
#
# Those runs are supposed to be the *fast* path — the whole point of the
# dashboard's Refresh buttons is not waiting for the next cron. Installing the
# full requirements.txt made them slow for no reason: a 2026-09-22 refresh
# spent ~2m45s of its 4m15s on pip, almost all of it on torch,
# sentence-transformers, openai-whisper and yt-dlp. None of those are reachable
# from scripts/run_afternoon.py --only:
#
#   sentence-transformers  embedding dedup, imported lazily inside
#                          processing/deduplicator.py and only by the news
#                          collection stage of run_daily.py
#   openai / anthropic     summarizer; every refresh mode is explicitly no-LLM
#   openai-whisper, yt-dlp YouTube transcripts, which don't run on CI at all
#   streamlit              the dashboard, not the collectors
#   reportlab              the dashboard's PDF export
#
# tests/test_slim_requirements.py imports every module the refresh path can
# reach and fails if one of them needs something that isn't here, so this
# cannot silently drift out of date.
#
# The full requirements.txt still backs daily.yml, in_season_pm.yml and
# podcasts.yml, which do run the summarizer and the deduplicator.
